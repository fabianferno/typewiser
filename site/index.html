Common questions

Does my audio get uploaded anywhere?

Not by default. Speech-to-text uses Apple’s on-device Speech framework. Only if you switch to a whisper.cpp server does audio leave the app, and that server is one you run. If you choose a cloud cleanup model, only the text transcript is sent, to the provider you picked, with your own key.

Do I need an account or subscription?

No. TypeWiser is free and open source. Local mode costs nothing to run. Cloud cleanup bills against your own Bedrock, OpenAI, or Anthropic account.

Which apps does it work with?

Anything that accepts pasted text. TypeWiser puts the cleaned text on the clipboard and sends ⌘V to whatever app has focus.

Why does it need Accessibility permission?

To notice the 🌐 key from any app and to paste with ⌘V. Without it, macOS silently drops both. It also lets TypeWiser read text near your cursor so names are spelled the way they already appear.

The emoji picker opens when I press 🌐.

Go to System Settings → Keyboard → “Press 🌐 key to” and choose Do Nothing.

How heavy is local mode?

The local cleanup model runs through llama.cpp and holds around 17 GB of RAM while active. Switching to a cloud model shuts the local server down and gives that memory back right away.

Does it understand my accent?

Choose a speech locale in Settings that matches how you speak, like English (India) or English (UK). It often makes a large difference over the system default.

Can I contribute?

Yes. It’s a Swift package with a fast test suite that never touches the network. Open an issue or a pull request on GitHub.
